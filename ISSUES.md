## 🟡 Важные — существенно влияют на впечатление жюри

### 4. `docs/cost-and-time.md` — таблица стадий полностью пустая
**Проблема:** Таблица `Стадия / Время / Токены / Стоимость / Часы человека / Источник` заполнена пустыми ячейками. Файл обещает прозрачность, но показывает прочерки. Жюри оценивает прозрачность отдельным критерием.  
**Правка:** Вставить реальные или оценочные данные по демо-прогону из `projects/demo/manual-costs.csv` и `run-log.csv`. Итого по демо: 180 человеко-минут, 0 ₽. Добавить хотя бы строку «demo-итого» с этими цифрами.

### 5. `docs/portability.md` — Antigravity помечен как «не подтверждено»
**Проблема:** Раздел «Поведение Antigravity» содержит статус «не подтверждено», хотя вся работа агента велась именно в Antigravity. Это противоречие — жюри видит, что агент работал в среде, которую сам же описывает как непроверенную.  
**Правка:** Обновить раздел. Зафиксировать: «Подтверждено 2026-11-21: Antigravity читает `AGENTS.md`, выполняет скрипты через встроенный терминал, `check.py --all` вернул 0 ошибок.»

### 6. `evals/fixtures/bad_project/secret.md` — фиктивный ключ выглядит как утечка
**Файл:** `evals/fixtures/bad_project/secret.md` содержит строку с фиктивным ключом вида `sk-FAKE...`.  
**Проблема:** Файл нужен для теста секрет-скана, но фиктивный ключ выглядит как настоящий OpenAI-ключ и может насторожить жюри при code-review.  
**Правка:** Заменить на явно фиктивный формат (например `sk-TEST-PLACEHOLDER`) и добавить комментарий в начале файла: `# Намеренная имитация утечки для тестирования check.py --secrets`.

### 7. `docs/submission.md` — не упоминает `git push` перед проверкой жюри
**Проблема:** Инструкция «Как проверить проект за 3 минуты» начинается с `git clone ...`, но не предупреждает, что клон может быть на 1 коммит позади, если push не сделан.  
**Правка:** Добавить в начало секции: `> ⚠️ Перед клонированием выполните: git push origin main`.

**Правка:** Сбалансировать — показать оценку 7–8 по сложным критериям с честным обоснованием слабых мест, которые можно устранить. Это повышает доверие.
