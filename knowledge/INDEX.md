# Карта знаний

| Файл | Когда открывать | Связанные скиллы |
|---|---|---|
| `methods/evidence.md` | перед сбором и разбором доказательств | `collect-sources`, `evidence` |
| `methods/interviews.md` | перед любым интервью или синтетической персоной | `evidence`, `communication` |
| `methods/unit-economics.md` | при расчётах пользы, затрат и доходов | `product-strategy` |
| `methods/communication.md` | при выборе барьера и сообщения | `communication` |
| `../agents/persona-interviewer.md` | при моделировании синтетических интервью | `evidence` |
| `../agents/data-analyst.md` | при количественном анализе и расчётах | `product-strategy` |
| `../agents/ux-analyst.md` | при разборе интерфейсов и пользовательских путей | `collect-sources` |
| `../agents/router.md` | при выборе роли/субагента для следующего шага | все стадии |

Правило: методы живут здесь, материалы проекта — в `projects/`, состояние — в `projects/<slug>/state.md`. Не смешивать.
