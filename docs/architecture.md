# Архитектура и лимиты

**Статус:** каркас, день 4 из 19. Скрипты и содержательные тексты появятся 5–7.11. Документ фиксирует рамки, чтобы дальше не перестраивать репозиторий.

## 1. Тезис
Репозиторий — протокол принятия решений, а не фреймворк и не приложение. Рантайм — IDE-агент, который читает `AGENTS.md` и `skills/`. Ценность — дисциплина доказательств, возобновляемость и прослеживаемость. Число агентов, объём инструкций и новизна технологий сами по себе не являются преимуществом.

## 3. Четыре контракта
```
state.md:    stage, status, next_action, human_gate, do_not_redo, open_questions, updated
sources.csv: id,url,title,type,published,accessed,license,quote,confidence,status
claims.md:   C07 [FACT|S04] ...   C08 [HYP] ...   C09 [FORECAST] ...
run-log.csv: ts,stage,actor,action,tool,artifact,status,note,tokens_in,tokens_out,cost_rub,human_min,cost_source
```
`tokens_*`, `cost_rub`, `human_min` заполняет человек вручную из панели провайдера. Агент эти поля не выдумывает.

## 4. Хуки
- **Git:** `.githooks/pre-commit` — заглушка, с 5.11 запускает `scripts/check.py --staged`.
- **IDE:** `.claude/settings.json`, `PostToolUse` на `Write|Edit` — запускает `scripts/check.py --hook` после записи. Скрипт сам решает, относится ли файл к `claims.md`, `sources.csv` или `state.md`.
- **DeepSeek harness:** подключается мостом `@deepseek-ai/dsh-hooks-claude-code` с `configPath: ./.claude/settings.json`. Если мост не включён, хук не срабатывает — проверка запускается вручную.
- **Другие среды:** как повторить — `docs/portability.md`.

## 5. Routing
| Задача | Среда/модель | Почему |
|---|---|---|
| Поиск и чтение источников | DeepSeek harness + веб-поиск | основной рабочий контур, поиск проверен |
| Длинный синтез, стратегии, код | DeepSeek Flash 4.1 | длинный контекст, дешевле |
| Скриншоты, таблицы, разбор PDF | Gemini Flash 3.8 | мультимодальность |
| Независимая критика и проверка собранных материалов | Gemini, без поиска | второй контекст, не ищет и не подменяет источники |
| Факт-чек выборки | человек | 10 цитат, финальное решение |

Бюджет: 0 ₽ по умолчанию. Резерв 500–1000 ₽ — только если бесплатные лимиты закончатся в день записи видео. Платные сервисы в критический путь не входят.

## 6. Стоимость
Агент пишет действие, инструмент, артефакт и статус. Токены и рубли снимаются вручную из панели провайдера раз за стадию и вносятся в `run-log.csv`. В `docs/cost-and-time.md` фиксируется формулировка «измерено вручную по панели провайдера». `scripts/report.py` принимает `manual-costs.csv` (создаётся вручную при первом замере) и не генерирует цифры сам.

## 7. Baseline
Объективные метрики: число источников, доля утверждений с рабочей ссылкой (выборка 10), время до результата, стоимость, число правок человека. Оценка Gemini по rubric — дополнение, не замена. Шаблон — `evals/baseline.md`.
