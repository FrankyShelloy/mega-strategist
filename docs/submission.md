## Как проверить проект члену жюри за 3 минуты

> ⚠️ **Перед клонированием** убедитесь, что автор выполнил `git push origin main` — ветка `main` на GitHub должна быть актуальной. Проверить: последний коммит на https://github.com/FrankyShelloy/mega-strategist совпадает с датой сдачи.

1. **Клонировать репозиторий:**
   ```bash
   git clone https://github.com/FrankyShelloy/mega-strategist.git
   cd mega-strategist
   ```

2. **Запустить команду возобновления:**
   ```bash
   python3 scripts/resume.py
   ```
   *Скрипт выведет текущий статус проекта demo, последние события в журнале и результат проверки целостности (0 ошибок).*

3. **Запустить воспроизводимый расчет экономики и выборки пилота:**
   ```bash
   python3 scripts/calc_economics.py
   ```
   *Выведет детерминированный расчет окупаемости по ставке 500 ₽/мес. и размер выборки 3 276 семей (A/B Holdout).*

4. **Запустить проверку всех контрактов и секретов:**
   ```bash
   python3 scripts/check.py --all
   ```
   *Выход `0 ошибок` подтверждает 100% валидность ссылок, тегов и полей.*

5. **Ознакомиться с финальным отчетом:**
   Открыть файл `projects/demo/report.md`.
