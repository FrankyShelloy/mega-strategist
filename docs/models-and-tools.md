# Модели, сервисы и инструменты

В проекте используется прагматичный стек нейросетевых моделей, детерминированных CLI-инструментов и структурированных баз знаний, обеспечивающий максимальную точность при нулевых прямых расходах.

## Перечень используемых компонентов

| Модель / инструмент / сервис | Для чего используется в пайплайне | Стоимость | Ограничения и особенности |
|---|---|---|---|
| **DeepSeek V3 / R1** (через Harness / API) | Постановка задачи, синтез доказательств, разработка стратегий и плана проверки | 0 ₽ (в рамках бесплатного тарифа / квот) | Требует явной верификации арифметики скриптами |
| **Gemini Flash / Pro (Google DeepMind)** | Мультимодальный анализ брифа (PDF), извлечение таблиц, независимая критика вариантов | 0 ₽ (в среде Antigravity / Google AI Studio) | Работает в чистом контексте для исключения предвзятости (confirmation bias) |
| **Python 3.11+ Standard Library** (`check.py`, `resume.py`, `report.py`, `review.py`, `calc_economics.py`, `simulate_persona.py`) | Детерминированная валидация целостности, расчет формул юнит-экономики, генерация отчетов и управление состоянием | 0 ₽ (локальное исполнение) | 100% повторяемость, нулевая зависимость от внешних серверов |
| **Библиотека `requests`** (`verify_urls.py`, `baseline_run.py`) | Проверка доступности веб-источников и автоматический сбор сравнительного baseline | 0 ₽ (открытое ПО) | Опциональная зависимость; ядро работает без неё |
| **IDE-агенты (Cursor / Claude Code / Antigravity / Harness)** | Среда интерактивного диалога с продакт-менеджером, чтение `AGENTS.md` и вызов скиллов | 0 ₽ (интегрированные IDE) | Следование правилам `AGENTS.md` и остановка на шлюзах G1–G3 |
| **Человек-руководитель (Human-in-the-loop)** | Утверждение рамок на шлюзах G1, G2, G3; ручной замер времени и затрат | 0 ₽ (рабочее время команды, ~3 часа) | Финальная юридическая и бизнес-ответственность |

## Что НЕ используется и почему

1. **Тяжелые мультиагентные платформы (CrewAI, AutoGen, LangGraph, OpenClaw):**
   - *Причина отказа:* Создают колоссальный оверхед по токенам (до 10x), склонны к зацикливанию, сложны в отладке жюри и скрывают ход рассуждений за сложной абстракцией. Папка с протоколом (`AGENTS.md` + `skills/` + `scripts/`) прозрачнее, дешевле и запускается «из коробки» в любой IDE.
2. **Векторные базы данных (Pinecone, ChromaDB, Weaviate, Qdrant):**
   - *Причина отказа:* Объем материалов продуктовой стратегии (15–30 источников, до 50 страниц текста) полностью укладывается в длинный контекст современных LLM (128k–1M токенов). Векторный поиск добавляет риск потери контекста при чанковании и требует развертывания отдельного сервиса.
3. **Платные поисковые API (SerpAPI, Tavily):**
   - *Причина отказа:* Открытые источники валидируются встроенным веб-поиском среды и проверяются скриптом `verify_urls.py`, что сохраняет бюджет 0 ₽.
4. **Сложный MCP-сервер в критическом пути:**
   - *Причина отказа:* Все необходимые операции (чтение файлов, CLI-проверки, расчеты) уже доступны IDE. MCP-протокол добавлен как опциональный интерфейс для внешних систем, чтобы не создавать точку отказа при запуске жюри.
