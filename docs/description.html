1Архитектура агента

Тезис

Репозиторий — это протокол принятия решений, а не фреймворк и не приложение. Рантайм — IDE-агент (Cursor / Claude Code / Antigravity / DeepSeek Harness), который читает AGENTS.md и вызывает skills/. Ценность — дисциплина доказательств, возобновляемость и прослеживаемость.

Работа с контекстом и знаниями

  • Постоянные инструкции — AGENTS.md, skills/: читаются в начале каждой сессии.
  • Методологическая база — knowledge/methods/: открывается агентом по карте knowledge/INDEX.md только когда нужна конкретная методика.
  • Материалы проекта — projects/demo/: читаются при переходе на нужную стадию.
  • Состояние сессии — projects/demo/state.md: единственный источник правды о том, где остановился агент. Скрипт resume.py восстанавливает контекст с нуля за 3 секунды.

Хуки и автоматизация

  • Git pre-commit hook (.githooks/pre-commit): запускает check.py --staged перед каждым коммитом. Подтверждено.
  • IDE PostToolUse hook (.claude/settings.json): вызывает check.py --hook после каждой записи в claims.md. Статус: задокументировано, активирует человек при настройке среды.
  • Antigravity (подтверждено 2026-11-21): читает AGENTS.md, выполняет все скрипты через встроенный терминал, 0 ошибок при check.py --all.

Почему НЕ используются тяжёлые фреймворки

  • CrewAI / AutoGen / LangGraph: создают оверхед до 10× по токенам, склонны к зацикливанию, скрывают ход рассуждений. Папка с протоколом прозрачнее, дешевле, запускается в любой IDE.
  • Векторные БД (Pinecone, ChromaDB): 15–30 источников укладываются в длинный контекст современных LLM. Векторный поиск добавляет риск потери контекста при чанковании.
  • Платные поисковые API (Tavily, SerpAPI): встроенный веб-поиск IDE достаточен; бюджет сохранён на 0 ₽.

3Ключевые промпты и инструкции агента

Системный промпт: AGENTS.md

Главный файл (v1.1). Содержит: карту стадий, 4 формата данных-контракта, правила доказательств, список субагентов, правила шлюзов G1–G2–G3, запреты (не выдумывать цифры, не выдавать синтетику за факт, не продолжать после шлюза без ответа человека).

Карта скиллов

СкиллКлючевой промпт
intakeУточнить вопрос, цель, получателя, ограничения. Спрашивать только то, что влияет на следующий шаг.
research-planПостроить дерево вопросов, меняющих решение руководителя. Остановиться на G1.
collect-sourcesСобирать только открытые материалы. Фиксировать прямые цитаты, URL, дату доступа, лицензию в sources.csv. Лимит: до 20 источников.
evidenceМаркировать каждое утверждение: [FACT], [HYP] или [FORECAST] с ссылкой [S#]. Если факта нет — фиксировать в gaps.md, не домысливать.
optionsНе менее 4 содержательно разных вариантов, включая статус-кво и закрытие. Роль критика — найти механизмы провала. Остановиться на G2.
product-strategy5 обязательных разделов: CJM, матрица согласий (152-ФЗ), экономика, пятистрочная таблица показателей, осознанные отказы.
communicationБарьеры → ключевое сообщение → RTB → матрица «Обещание→Фича→Источник». Обещания соответствуют продукту.
test-planA/B Holdout: выборка N (MDE, power 80%), guardrails, стоп-правила, сроки. Остановиться на G3.
decision-recordЗафиксировать решение, владельцев, метрики, дату пересмотра, условия отката.
reviewНайти устаревшие основания (>365 дней) и наступившие сроки пересмотра. Не переписывать решения — только сигнализировать.

  • G1 (стадия 01): человек скорректировал приоритет — фокус на семейные группы, мультиномера отложены до Q4. Агент не продолжал до явного ответа.

6Заявленные возможности и ограничения

Что агент делает

  • Превращает размытый запрос в строгую карточку и дерево вопросов, меняющих решение.
  • Работает только с открытыми источниками; сохраняет прямые цитаты, URL и лицензии.
  • Маркирует каждое суждение: [FACT], [HYP], [FORECAST] + [S#]. Скрипт check.py проверяет автоматически.
  • Генерирует ≥4 содержательно контрастных варианта, включая статус-кво и закрытие.
  • Рассчитывает воспроизводимую юнит-экономику и статистическую мощность пилотов (Python stdlib, без LLM-арифметики).
  • Возобновляет работу после перерыва с помощью resume.py — агент не начинает заново.
  • Ведёт журнал решений с датами пересмотра и условиями отката.

Что агент НЕ делает

  • Не выдумывает цифры — если факта нет, фиксирует пробел в gaps.md.
  • Не выдаёт синтетические интервью за реальный спрос — маркер [SYNTHETIC-PERSONA] обязателен, статус [FACT] недоступен.
  • Не принимает стратегические решения самовольно — на G1, G2, G3 переходит в waiting_human и блокируется до явного ответа.
  • Не использует закрытые данные МегаФона — только открытые источники.
  • Не создаёт веб-сервисов или мультиагентных оркестраторов — переносимая папка, работающая в любой IDE.

Где агент может ошибаться

  • Задержка обновления источников: тарифные сетки меняются быстрее, чем обновляются открытые страницы.
  • Смещение веб-отзывов: форумы и сторы смещены в сторону крайнего негатива — «молчаливое довольное большинство» не отражено.
  • Юридические тонкости: применение ст. 53 и 63 Закона «О связи» требует финальной визы корпоративного юриста.
