# Дополнительные возможности

## MCP: сознательный отказ
MCP не нужен в критическом пути: у агента уже есть файловая система, веб-поиск и CLI-проверки, а данных, которые требуют отдельного протокола, нет. Подключение MCP добавило бы жюри шаг настройки и ещё одну точку отказа, не улучшив ни один критерий. Поэтому отказ остаётся.

Крошечная MCP-обёртка над `check.py` и реестром источников (два read-only инструмента: `check_project`, `list_sources`) записывается как **P2** и делается только после E2E-гейта 15.11. Если E2E не пройден — обёртка не делается. Оценка пользы: удобство для внешних клиентов; оценка стоимости: 2–3 часа и один новый риск в инструкции запуска.
