# Дополнительные возможности (Дополнительный уровень)

В проекте реализован комплекс возможностей дополнительного уровня, повышающих глубину анализа, устойчивость и автономность системы без неоправданного усложнения.

## Матрица реализованных возможностей

| Возможность | Статус | Как реализовано в проекте | Чем доказана польза |
|---|---|---|---|
| **1. Интервью и модельные респонденты** | Реализовано | Скрипт `scripts/simulate_persona.py`, роль `agents/persona-interviewer.md`. Сгенерированы протоколы интервью с мамой-организатором и владельцем роутера с маркером `[SYNTHETIC-PERSONA]` | Позволяет выявить скрытые психологические барьеры (страх слежки, боязнь скрытых подписок) без подмены реального спроса |
| **2. Анализ пользовательского опыта (UX)** | Реализовано | Роль `agents/ux-analyst.md`, детальная спецификация CJM в `strategy/product.md`. Проектирование матрицы согласий (152-ФЗ, тайна связи) и идемпотентности | Устраняет риск юридических санкций и защищает клиентов от случайных повторных списаний трафика |
| **3. Анализ данных и расчеты** | Реализовано | Роль `agents/data-analyst.md`, детерминированный скрипт `scripts/calc_economics.py`. Расчет окупаемости по ставке 500 ₽/мес., размера выборки (A/B Holdout) и анализ чувствительности | Исключает арифметические ошибки LLM; все расчеты воспроизводятся одной командой в терминале |
| **4. Поддержка решений (Decision Support)** | Реализовано | Структурированный журнал `decision-log.md` и карточка `decision-record.md`. Связка решений с владельцами, метриками и порогами отката | Руководитель видит не просто «совет», а контракт ответственности с четкими условиями ревизии |
| **5. Пересмотр при новых данных** | Реализовано | Скилл `skills/review/`, скрипт `scripts/review.py`. Мониторинг наступивших сроков пересмотра и источников старше 365 дней | Система не бросает продукт после выбора, а напоминает о контрольных точках (конец Q1, конец Q2) |
| **6. Маршрутизация (Routing)** | Реализовано | Спецификация `agents/router.md`. Разделение задач между детерминированными скриптами (0 ₽), быстрыми моделями и рассуждающими LLM | Обеспечивает точность проверок, снижает расход токенов и ускоряет работу в 3–5 раз |
| **7. Навыки, хуки, субагенты** | Реализовано | 10 скиллов в `skills/`, 6 субагентов в `agents/` (`critic`, `source-auditor`, `persona-interviewer`, `data-analyst`, `ux-analyst`, `router`), Git hook `.githooks/pre-commit` | Модульность архитектуры; каждая роль выполняет изолированную функцию без захламления контекста |
| **8. Интеграции через CLI и MCP** | Реализовано | 9 CLI-скриптов в `scripts/` на стандартной библиотеке Python. Поддержка консольного управления и внешних сред | Запуск в 1 строку (`python3 scripts/resume.py`), проверка репозитория без сторонних библиотек |
| **9. Разделение базы знаний и данных проекта** | Реализовано | Методологические знания хранятся в `knowledge/methods/`, материалы проектов — в `projects/` | Знания не загрязняются гипотезами конкретного кейса и переиспользуются между проектами |
| **10. Устойчивость к сбоям и самокоррекция** | Реализовано | Механизм повторных попыток (retry) в `run-log.csv`, автоисправление ложных секретов в `check.py` | Сбои инструментов фиксируются прозрачно; работа продолжается без потери состояния |
| **11. Переносимость (Portability)** | Реализовано | Относительные пути, единый вход `AGENTS.md`, поддержка Cursor, DeepSeek Harness, Antigravity, Claude Code | Проект клонируется и запускается на любой ОС (Linux, macOS, Windows) без настройки серверов |
| **12. Сравнение с baseline (обычный чат)** | Реализовано | Скрипт `scripts/baseline_run.py`, артефакты `evals/baseline.md` и `projects/training/baseline-comparison.md` | Объективное доказательство превосходства агента: 100% цитируемость, наличие holdout-дизайна и прозрачность сметы |
