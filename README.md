# mega-strategist

**Статус: каркас, день 4 из 19.** Рабочий сквозной путь появится 7.11, демо-кейс — после брифа 8.11. Сейчас здесь только структура, правила и пустые шаблоны.

Репозиторий-протокол для руководителя цифрового продукта: размытый запрос → проверяемая картина → варианты → продуктовая и коммуникационная стратегии → план проверки → пересмотр при новых данных. Это не сайт и не приложение; агент работает внутри IDE, которая читает `AGENTS.md` и `skills/`.

## Быстрый старт (после 7.11)

```bash
git clone https://github.com/FrankyShelloy/mega-strategist.git
cd mega-strategist
python3 scripts/resume.py
```

Дальше открой `AGENTS.md` и `projects/demo/state.md`. Первый запуск займёт до 15 минут, полный прогон — 60–90 минут.

## Требования

- Любая среда, читающая `AGENTS.md`: DeepSeek harness, Cursor, Claude Code, Antigravity.
- Python 3.11+ — только для проверок и отчётов, без сторонних пакетов.
- Ключи и платные сервисы не обязательны. Бюджет: 0 ₽, резерв 500–1000 ₽ на случай исчерпания бесплатных лимитов в день записи видео.

## Что внутри

- `AGENTS.md` — постоянные правила и карта стадий.
- `skills/` — 10 скиллов, по одному на стадию.
- `knowledge/` — методы и навигация, отдельно от материалов проекта.
- `projects/demo/` — артефакты демонстрационного кейса.
- `projects/training/` — тренировочный кейс «падает удержание», остановлен на G1.
- `scripts/` — `check.py` и `resume.py` готовы; ещё три скрипта — 6.11.
- `docs/` — архитектура, стоимость, границы, инструкция для жюри.
- `evals/` — кейсы, rubric и сравнение с baseline.
