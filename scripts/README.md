# scripts/ — проверки и отчёты

`check.py` и `resume.py` готовы 4.11. `report.py`, `review.py`, `new_project.py` — день 6.

| Скрипт | Назначение | Контракт |
|---|---|---|
| `check.py` | валидатор | `--hook` — JSON из stdin, проверяет `claims.md`/`sources.csv`/`state.md` изменённого проекта; `--staged` — полная проверка рабочего дерева перед коммитом; `--secrets` — только скан; `--root <path>` — проверка фикстуры; exit 0/2 |
| `resume.py` | брифинг для нового чата | `--project projects/<slug>`; печатает `state.md`, последние 10 строк `run-log.csv`, вывод `check.py` |
| `report.py` | отчёт и смета | собирает `report.md`; принимает ручные токены/рубли из `manual-costs.csv` (создаётся вручную), не выдумывает их |
| `review.py` | пересмотр | решения с наступившей датой и утверждения с устаревшими источниками |
| `new_project.py` | новый кейс | копирует скелет `projects/demo/` в `projects/<slug>/` и заполняет `state.md` |

Общие правила: Python 3.11+, только stdlib, относительные пути от корня репозитория, никаких записей вне проекта. `check.py` намеренно не ходит в сеть и не проверяет доступность URL.
